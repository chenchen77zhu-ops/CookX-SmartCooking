| 依赖 | 当前观察 | 页面行为及待支持项 |
|---|---|---|
| 日期编辑 | PUT 忽略 purchase_time、expiry_date、add_time | 日期只读；待明确可编辑字段与响应回传 |
| 清空字段 | PUT shelf_life=null 报错；storage 空值语义不明确 | 不允许清空已有值；需约定 null/省略区别 |
| 时间格式 | 新增接受 ISO 字符串；add_time 服务端生成无时区；鲜度将无时区按 UTC 处理 | 用户输入转带 Z 的 ISO；旧时间展示原值，不声称时区准确，待统一存储时区 |
| 保质期精度 | 新增支持正小数，PUT 转 int，批次 key 也转 int | 保留未改小数；编辑新值只接受整数；待统一精度 |
| 批次归并 | 名称、入库日、储存方式、整数保质期作为 key，忽略购买/到期日期 | 日期冲突会无法验证，显示待核对；需支持按不同购买/到期日期分批 |
| 写入幂等性 | POST 无幂等键，响应没有 item_id | 前端用户隔离保存待确认记录，超时只读核对，待提供幂等键及保存后记录 |

新增、识别入库发送现有接口支持的字段。编辑只发送变化的 name/quantity/storage_type/shelf_life。
保存按业务状态与回读字段验证；回读失败不自动重发。批次冲突不通过删除重建规避。
