# 暂缓任务启动前软件联调

基线 main `4ca38e3`（已重新核对远端）。发现并修复：全局口味偏好导致账号共用；AI 菜谱缺营养数据时被补上固定数值。旧偏好仅显式导入当前账号，缺失营养为 null。

本轮通过：346 项后端、68 项前端、3 项温度仿真、9 套浏览器脚本、Android assembleDebug/testDebugUnitTest。新增偏好切换、显式导入与其他账号不受影响的回归。原流程涵盖真实隔离本地 API、响应丢失、重复写入、菜谱异常、提醒、计时及温度模型回退。

云端视觉/菜谱/语音仍使用测试替身。真实手机语音、锁屏通知、持续蓝牙与烹饪效果待实测。现有账号体系的身份授权与 JSON 存储将在下一基础分支升级，当前版本不能据此认定具备多人访问权限保护。

软件联调门槛通过后进入 SQLite/认证基础，再分功能实现已确认的 13 项暂缓任务。离线分支只接收单向同步，始终不合入 main。
