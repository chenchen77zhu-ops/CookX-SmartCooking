# 厨艺成长与完成同步

`POST /api/v3/growth/completions` 接受用户主动确认的完成会话。每账号/会话只有一个不可变事件；同凭证或新凭证重试同内容均不重复计数，改写内容返回冲突。菜谱、开始/完成时间及版本保存为个人历史。生成菜谱、计时回调、扣库存均不自动计次。

完成核对入口先保留本地完成，再保存待同步凭证。网络失败不撤销完成或库存结果，成长页可重试；账号切换不会把待同步数据发给新账号。旧本机完成记录只在用户确认后导入并单列来源。

`GET /api/v3/growth` 给出次数、菜谱种类、已标注方法、时间变化和历史。历史可复刻，数据不自动发布社区，不是专业技能认证。

验证：2 项真实 SQLite/API 场景、2 项客户端队列故障/账号隔离测试，前端合计 70 项通过；移动页面确认导入→刷新不重复→再次导入排除→历史复刻通过。真实多人长期行为数据尚不足。
