# 系统烹饪挑战

依赖厨艺成长的服务端去重完成事件，新增三个主动加入的系统挑战：加入后完成一餐、三种菜谱、七天内三次完成。未加入、加入前完成及旧本机记录导入不计入；同一会话重试不增加进度。七天窗口结束后未达标显示已结束，不自动续期或清零。

接口 GET /api/v3/challenges 与 POST /api/v3/challenges/{id}/join，后者有原凭证重试保护。首版只允许预置挑战。达标状态保存，重新登录/刷新继续读取。挑战次数不表示专业技能等级。

验证：真实 SQLite/API 覆盖加入前排除、重复加入、重复完成、导入排除、不同菜谱计数、七天到期和账号隔离；移动页面加入→真实完成事件→刷新进度→页面重载通过；前端构建通过。
