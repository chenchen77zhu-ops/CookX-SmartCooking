# 正式版服务器配置

构建前设置 `VITE_BACKEND_ORIGIN` 为手机可达的后端 origin（例如局域网电脑的 `http://192.168.x.x:8000`），然后运行前端构建、Capacitor sync 和 Android 构建。这个变量只存公开服务地址，不得填写密钥。未指定时保留原生原地址，浏览器仍使用同源代理。

数据库/服务器尚未部署时请下载独立离线分支的 APK；正式版的登录、库存与推荐仍需可达后端。环境变量不意味着服务器已经上线。连接电脑测试时，后端监听与防火墙必须允许手机到达服务。

离线版的运行时、测试样本及不同应用 ID 只保存在 `feat/p2-local-test-apk`。正式 main 的 CI 检查这些离线文件没有混入；不得将离线分支作为合并来源。允许 main 的正式修复单向同步到离线分支。
