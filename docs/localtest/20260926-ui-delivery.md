## 安装问题的证据与限制

用户反馈旧 UI APK 的安装器直接退出，应用管理也找不到 CookX。因此没有证据证明安装成功，不能仅归因于桌面没有自动添加快捷方式。

旧包 `CookX-81b02e2-debug.apk` 是正式包名 `com.smartcooking.app`，code 4，含 MAIN/LAUNCHER 入口、应用图标、有效签名，ZIP 对齐检查通过。它不是旧离线包的升级。无手机连接和安装器日志，本轮不声称找到手机端根因或已完成真机安装验证。

新离线包保持旧离线包身份，使用同一本机签名并提高版本号。构建过程校验实际 APK 的包名、名称、版本、桌面 Activity、DEX 类、图标、签名、对齐和包内离线标记，输出 `apk-verification.json`。发布页 APK 与每次 Actions 自动生成的调试签名可能不同，覆盖安装优先使用发布页 APK。

若新包仍无法安装，将手机 USB 调试连接到电脑，在授权后执行：

```powershell
./frontend/scripts/install-localtest-diagnostic.ps1 -Apk <APK绝对路径> -Adb <adb.exe绝对路径>
```

该脚本只对指定 APK 执行 `adb install -r`，保存 Android 原始错误码；成功后查询本包并尝试打开启动页。不绕过签名或版本检查，不自动卸载、降级或清除数据。没有设备时直接停止。
