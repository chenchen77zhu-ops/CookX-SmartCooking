# 十三项正式功能后的离线演练版

本分支永久独立，只有 main → 本分支的普通同步合并，不能合入 main。包名 com.smartcooking.app.localtest，和正式版可以共存。正式版完整接口/算法需要本机或局域网后端；离线版使用本机 localStorage，没有服务器或数据库。

原有库存、日期编辑、识别确认示例、推荐示例、烹饪步骤/计时、固定指令、调整、完成核对和温度回放继续可测。新多人页面明确转入“多人功能离线样例”：同一手机切换 A/B 角色演练共享数量、采购认领/购买/实际入库、晒单文字/评论/点赞/榜单、剩菜条件提示、成长/挑战/徽章和明确反馈。菜单仅显示七日布局，不运行 CP-SAT，反馈不训练模型，图片不上传。样例功能不能冒充真实跨设备业务验收。

71 项通用前端测试、9 项离线运行时测试通过。两组浏览器脚本拦截全部 API 与外部网络，实际请求数为 0，页面错误数为 0；覆盖刷新持久化、两角色隔离、原扣减响应丢失核对、新样例流程与移动布局。Android 构建/单元检查由独立构建脚本及分支 CI 记录。系统语音、锁屏、持续硬件仍需手机验证。
