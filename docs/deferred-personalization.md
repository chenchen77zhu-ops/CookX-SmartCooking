# 长期偏好学习：运行链路与对照门槛

主动开启后，每账号每道标准菜谱保留一份明确喜欢/不喜欢反馈，重复同值不追加训练样本。收藏、复刻与完成单独记录为无标签行为，不将浏览、未点击、扣库存或操作频次当负反馈。数据保存在本机后端 SQLite，账号隔离。

独立正则化逻辑回归使用菜谱标签和烹饪方法，固定学习率 0.25、L2 0.08、800 次迭代。至少 12 道菜反馈，按服务端时间前 75% 训练、后 25% 测试；相同时间组不跨集合，词表只从训练前缀建立。两部分均需正负样本。比较测试集成对 AUC 与原单餐分，同时要求对数损失不劣于训练偏好比例常数基线。仅严格优于原排序且通过损失检查时接受；之后对全部已知反馈拟合部署模型。

重排接口只接收原算法已经过滤的候选，不新增菜谱，不改变总分、F 分量或其他权重；菜单硬约束求解不使用该模型。模型值不是校准的偏好概率/准确率，页面展示标签理由、版本及对照口径。数据不足、反馈更新、关闭、模型损坏时回退原排序。

/API 路径：/api/v3/learning，settings，feedback/{recipe_id}，train，reset。设置与反馈带版本，所有写入使用凭证。清除删除反馈、学习行为、模型及历史学习凭证中的内容，留下原凭证去重标记，旧请求重放不恢复已清除反馈。模型重置保留明确反馈；关闭保留数据但停止新行为收集与排序应用。

验证：时间划分/词表泄漏检查、冷启动、只有正样本、原排序已完美、候选集合及原分量不变、模型损坏回退、账号隔离、关闭、清除后旧请求重放；移动页面开启→反馈→训练不足回退→关闭→清除通过。实验配置、人工样本和失败案例见 docs/learning-experiment-results.json，可用 research/learning/run_experiments.py 重现。人工可分样本通过仅证明训练/部署管道可运行，不代表真实长期偏好收益。
