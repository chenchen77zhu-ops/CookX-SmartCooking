# 多人内测私人媒体边界

新头像校验真实 JPEG/PNG/WebP，限制 5 MB/1200 万像素并重编码去除元数据。头像和生成语音存入 SQLite，按账号读取；原静态目录在正式存储模式下停止公开访问。旧头像仅从当前账号记录的严格本地文件名读取并重新校验，历史静态文件目录需单独随迁移备份。新的数据库备份包含新增图片和音频。

个人页使用携带会话的请求获取 Blob，卸载时回收地址。未经本人上传的头像引用被拒绝，音频不能作为社区图片发布。社区图片只有用户主动发布后才对内测成员可见。账号删除清除归属媒体；已经发布作品的文字处理仍沿用社区删除规则。

验证：396 项后端回归通过，移动尺寸浏览器上传、预览、保存回读及刷新头像通过，同时修复头像编辑徽标样式误作用于头像主体导致点击区域折叠的问题。云 TTS 音色质量未在此测试中验证。
