# 跨功能联调记录

基于十三个功能分支组合，使用隔离的真实本地 SQLite、真实身份验证和两账号访问；视觉与云菜谱响应仍为测试替身。20 组移动尺寸浏览器脚本通过；独立后端地址设置脚本通过。全流程覆盖家庭邀请、采购认领、确认入库、菜单保存、复刻烹饪、家庭批次扣减、社区互动、成长与个性化反馈。

实测丢弃一次已提交的扣减响应，用原凭证重试后，100.5 克库存仅扣减一次 75 克，剩余 25.5 克。个人库存编辑和删除要求 If-Match（由 GET 返回的 _revision 提供）；旧客户端缺版本返回 428，冲突返回 409。个人新增和识别确认支持 Idempotency-Key，当前客户端每次确认保存凭证后再发送，不自动重发。

修复了家庭菜谱错误引用个人库存、偏好只保存在浏览器、切换家庭后旧响应覆盖、未知物品虚构克数等问题。服务端偏好与显式忌口在推荐前合并，评分公式不变。新增局域网地址设置，登录凭证绑定地址。没有视觉模型或云密钥时后端可启动，相关能力明确报不可用，不能解释为真实识别成功。

数据库恢复仅写入新路径并核对完整性，保留当前数据。Android 软件构建、手机实测与长期算法收益分开记录；语音、锁屏通知、持续蓝牙和真实烹饪仍待设备验证。
