# CookX 烹饪会话与设备链路升级简述

**摘要。** 本次升级以现有库存、菜谱和温度模块为基础，补齐从信息录入到烹饪完成的页面流程。采用可恢复的本地会话、受限语音指令和确认后写入机制，重点减少切页丢计时、误执行与重复扣库存的问题。

**实现方法。** 库存编辑支持购买、入库、到期日期及正小数保质期；未修改字段保留服务端原值。菜谱先经过统一结构校验，再进入用户隔离的烹饪会话。计时保存截止时间，刷新和锁屏后按真实经过时间恢复；步骤切换保留各步剩余时间，播报不改变计时。

语音采用点击后识别一句，只执行七类固定命令。低置信度、缺失置信度或多义结果需确认。四类本地调整仅修改未进入的后续步骤，提供修改预览、版本和撤销记录。提醒沿用后端鲜度与现有温度判断，并增加去重及 Android 本地通知。

完成烹饪与扣减库存分开记录。用户选择实际使用清单后才提交；同名多批次禁止自动扣减，响应丢失时只核对、不重发。蓝牙连接改由应用统一管理，切页不主动断开，并可导出原始温度帧及连接诊断。

**验证结果。** 62 项前端测试、146 项隔离后端测试、3 项仿真测试、浏览器完整流程和 Android 构建通过；七个草稿 PR 的三项 CI 检查均通过。回归中发现并修复了含营养信息的响应式菜谱无法复制到会话的问题。

**适用边界。** 本批没有更改 FreshFusion、推荐权重、温度算法或固件。测试中的视觉与云端语音/菜谱使用替身；真实硬件、系统语音、锁屏通知及手机后端联调仍待验收，不能将桌面测试写成原型机识别率。
