## 参考图 B 的位置核对

390×844、无额外系统安全区时，实测布局：温度区域 y=142–332；无卡片锅具区 y=332–484；阶段卡 y=484–556；趋势卡 y=568–666；建议卡 y=678–770；底栏 y=782–844。卡片间与底栏前均为 12px。边距 20px；短屏和有安全区时压缩卡片内留白，保留全部操作入口。此为按参考图重排和适配，不声称生成照片或系统状态栏与设计图逐像素相同。

烹饪主页面缩略显示当前步骤，点击建议卡或右上角“烹饪工具”可查看完整内容并操作上一/下一步。无可用预测时不人为补上参考图中的虚线；真实回放预测图单独验证。
